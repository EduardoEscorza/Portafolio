Backend / Microservicios

Backend para Transporte de Mercancías

Desarrollo de gran parte de los servicios del backend

Desarrollo de microservicios para una aplicación de transporte de mercancías, con localización de vehículos, persistencia de datos y negociación del precio del servicio.

Descripción del proyecto

Backend para una aplicación que conecta necesidades de traslado de mercancías con servicios de transporte. Contempla vehículos para carga a temperatura ambiente y transporte refrigerado, además de una dinámica para proponer y aceptar el precio del traslado.

Mi participación

Participé exclusivamente en el backend y desarrollé gran parte de sus servicios mediante una arquitectura de microservicios. Trabajé en APIs, acceso a datos mediante procedimientos almacenados e integración de la localización de vehículos y la persistencia de información.

También participé en la funcionalidad de negociación para proponer y aceptar el precio del servicio.

Aportaciones principales

  • Desarrollo de microservicios y APIs.
  • Integración con MySQL mediante procedimientos almacenados.
  • Integración de la localización de vehículos.
  • Persistencia de datos.
  • Funcionalidad de propuesta y aceptación del precio del traslado.

Tecnologías y recursos

Backend

  • Node.js
  • TypeScript
  • Moleculer

Base de datos

  • MySQL
  • Procedimientos almacenados
