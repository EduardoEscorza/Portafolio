Aplicación web / E-commerce

Plataforma de Comercio Electrónico

Desarrollo completo para un cliente

Desarrollo integral de una plataforma de comercio electrónico con gestión de productos, inventario y panel administrativo de ventas.

Descripción del proyecto

Primer proyecto desarrollado para un cliente, desde las conversaciones iniciales y el levantamiento de requerimientos hasta la finalización de la plataforma. La solución reúne la administración de productos e inventario con un panel enfocado en la gestión de ventas.

Mi participación

Me encargué del ciclo completo del desarrollo: comunicación inicial con el cliente, análisis de requerimientos, creación de procedimientos almacenados e implementación del backend y el frontend.

Funcionalidades principales

  • Gestión de productos.
  • Administración del inventario.
  • Panel administrativo.
  • Gestión de ventas.

Tecnologías y recursos

Lenguajes

  • JavaScript
  • PHP

Base de datos

  • MySQL
  • Procedimientos almacenados
